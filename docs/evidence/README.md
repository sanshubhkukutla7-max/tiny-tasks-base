# Evidence files

Add evidence without changing what it proves.

Suggested filenames:

- `expo-starter-phone.png` — original Expo sample running on the physical phone after interaction.
- `tiny-tasks-phone-added.png` — hosted Tiny Tasks after adding a uniquely named task.
- `tiny-tasks-phone-complete.png` — the same task toggled complete.
- `tiny-tasks-phone-refreshed.png` — state retrieved after Refresh or reopen.
- `pocket-board-word-count-phone.png` — PR #3 branch running in Expo Go with several words entered.
- `tiny-tasks-web-preview.png` — optional mobile-sized browser preview; label it as web-only.

For every screenshot, add the real date, device, backend (local or hosted), action performed, and result to `docs/progress.md`. Do not use a browser screenshot as proof of physical-device testing.
